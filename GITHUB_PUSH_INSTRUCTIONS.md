### **Method 2: Command Line with Personal Access Token**

1. **Create Personal Access Token**
   - Go to GitHub.com → Settings → Developer settings → Personal access tokens → Tokens (classic)
   - Click "Generate new token"
   - Select scopes: `repo` (full repository access)
   - Copy the token (you'll need it as password)

2. **Push Using Token**
   ```bash
   git push -u origin main
   ```
   - When prompted for username: `Abushahma736`
   - When prompted for password: Use your **Personal Access Token** (not your GitHub password)

### **Method 3: SSH Key (For Advanced Users)**

1. **Generate SSH Key**
   ```bash
   ssh-keygen -t ed25519 -C "230101120272@centurionuniv.edu.in"
   ```

2. **Add SSH Key to GitHub**
   - Copy the public key from `~/.ssh/id_ed25519.pub`
   - Add it to GitHub Settings → SSH and GPG keys

3. **Change Remote to SSH**
   ```bash
   git remote set-url origin git@github.com:Abushahma736/E-Commerce-AI-Automation-With-Admin-control-panel-website.git
   git push -u origin main
   ```
